# Product Definition: Ollama View for VS Code

## Initial Concept
The primary purpose of this Visual Studio Code extension is to provide a comprehensive interface for managing local Ollama models within the VS Code environment.

## Key Features
*   **Model Management**: View, pull, start, stop, and delete local Ollama models.
*   **Model Setup**: Configure model-specific system prompts and injection templates (prefixes/suffixes). Includes the ability to apply saved configurations for quick configuration.
*   **Model Framing**: Create, edit, and manage a library of system configurations (system prompts, injections) organized by tags. Built-in framings provide a starting point for specialized AI personas.
*   **Interactive Chat**: Engage in persistent, multi-turn conversations with Ollama models directly within VS Code, including message editing, regeneration, conversation branching, and chat-level framing overrides.
*   **Prompt Engineering Tools**: Visibility toggle for hidden system turns and injections, providing transparency for advanced prompt debugging.
*   **User Interface**: Intuitive side panel view with model list, status indicators, and context menus for quick actions.
*   **Seamless Integration**: Designed to integrate smoothly with the VS Code workflow, offering commands and views that feel native to the editor.

## Target Audience
Developers, researchers, and AI enthusiasts who utilize Ollama for local large language model (LLM) experimentation and development, and prefer a tightly integrated experience within their VS Code development environment.

## Value Proposition
Ollama View for VS Code streamlines the interaction with local Ollama models by centralizing management and conversation features directly within the IDE, enhancing productivity and user experience for VS Code users working with LLMs.

## Approach and Philosophy
Ollama View for VS Code is designed as a lightweight and ergonomic alternative to using terminal commands for specific Ollama interactions. It is not intended to replace other robust solutions that may utilize Ollama in the background, but rather to offer a convenient, integrated experience for VS Code users, enabling them to manage models and conduct quick chat experiments without switching contexts.
