# Track: E2E Testing Infrastructure

Establish a robust E2E testing framework with `vscode-extension-tester` and a mock Ollama server.

## Context
Manual testing of UI components like the tree view and notifications is time-consuming and error-prone. This track introduces automated End-to-End testing using a real VS Code instance and a mock server for the Ollama API.
